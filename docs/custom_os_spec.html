RaspyJack OS — Custom Lightweight Linux for CardputerZero

1. Problem Statement

The CardputerZero CM0 has 227 MB RAM. Stock M5Stack APPLauncher OS leaves ~43 MB free at idle (swap 172/226 MB used). Python + web server consume most memory. Goal: purpose-built OS with < 80 MB RAM at idle and < 5 s boot to UI.

Recommendation: Alpine Linux

  • 25 MB idle — busybox init + musl libc
  • apk packages — python3, py3-pillow, py3-numpy, py3-cryptography available
  • OpenRC init — lighter than systemd, fast boot
  • Read-only root — built-in via lbu
  • Familiar Linux — SSH, packages, standard tools

zram swap (no SD card)

modprobe zram num_devices=1
echo lzo > /sys/block/zram0/comp_algorithm
echo 64M > /sys/block/zram0/disksize
mkswap /dev/zram0 && swapon -p 100 /dev/zram0

64 MB zram = ~128 MB effective swap. No SD wear.

8. SPI Bus Contention Fix

import threading
_spi_lock = threading.Lock()

# Every SPI transaction:
with _spi_lock:
    spi.xfer2(data)

Global lock in _display_helper.py, _cc1101_driver.py, _st25r_driver.py.

10. Partition Layout & OTA

/dev/mmcblk0p1  256MB  vfat   /boot       (kernel, DTBs)
/dev/mmcblk0p2  512MB  ext4   /           (rootfs, read-only)
/dev/mmcblk0p3  rest   ext4   /data       (RaspyJack, loot, config)

/opt/raspyjack → symlink to /data/raspyjack. Rootfs reflashable without losing data.

11. Migration Plan

Phase 1: Strip current OS (1 day)

  1. Disable lightdm, bluetooth, avahi, cups, ModemManager
  2. Replace SD swap with zram
  3. apt autoremove --purge
  4. Target: ~100 MB used at idle

Phase 2: Alpine image (1-2 days)

  1. Build Alpine SD with all packages
  2. Copy RaspyJack + DT overlays
  3. Test all hardware

Phase 3: Hardening (1 day)

  1. Read-only rootfs + data partition
  2. Watchdog (bcm2835_wdt)
  3. OTA update mechanism
  4. Factory reset (hold KEY3 during boot)
